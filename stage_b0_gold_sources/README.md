## DailyMed label-diff puller (built, working, one real result)

`dailymed_label_diff.py` -- item 3 below, now built and validated. Uses DailyMed's official SPL version-history API (`/spls/{SETID}/history.json` + `getFile.cfm?type=zip` per version) to pull literal, dated, FDA-regulated before/after label text with zero LLM involvement anywhere in the ground truth. First real result: **AVANDAMET (rosiglitazone + metformin)**, SETID `0789dc6b-db34-44a6-8a5d-fdcc8e4ce8fd`, versions 2 (Dec 2009) vs. 6 (Sep 2012) -- the boxed-warning title itself changed from "MYOCARDIAL ISCHEMIA" to "MYOCARDIAL INFARCTION", and the underlying meta-analysis evidence base was updated (42 studies/14,237 patients -> 52 trials/16,995 patients), directly reflecting the post-2007 Nissen-controversy FDA label revisions. Saved to `data/gold_sources/dailymed_label_diffs.json`, tagged `matches_pilot_concept: C0289313` -- upgrades the rosiglitazone pilot concept (already used throughout the OGDA and Gate 2 experiments) from LLM-only to Gold-tier ground truth. Raw SPL XML kept in `stage_b0_gold_sources/raw/dailymed/` for provenance.

Usage: `python stage_b0_gold_sources/dailymed_label_diff.py --drug <name> --section "BOXED WARNING"`. Works for any drug with multiple DailyMed SPL versions -- not yet run against the other pilot concepts (rofecoxib, HRT products) or a broader drug list.
